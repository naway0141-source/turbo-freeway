# TURBO FREEWAY 3D

ポリゴンコクピット視点の3Dハイウェイ・ドライビングゲーム。Gemini が作成した単一 HTML ファイル作品を、てまごりゲーム集の一員として公開しています。

## 遊び方

- **GOAL RUSH**: 0km〜5km、4つの景観ゾーン（STAGE 1: WANGAN CITY〜）を駆け抜けてゴールを目指す。追い越し台数・最高速度・クリアタイムを記録
- **TRAFFIC: OFF**: 他車の出ない貸切高速クルーズモード

## 操作

- PC: [↑][↓][←][→] または WASD で運転 / [SPACE] ターボ / [C] 自動運転
- スマホ: 画面下部のタッチボタン、または画面左右スワイプで操舵

## 技術

- Three.js（r128）によるポリゴン描画、Tone.js によるサウンド、Tailwind CSS（いずれも CDN 読み込み）
- `index.html` 1ファイル完結
